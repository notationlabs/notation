Output refs are typed as refs (RFC 0027). `resource.outputRef(key)` returns an `OutputRef<T>`, `resource.credentials.<name>` a `CredentialRef<T>`, and `resource["~state"].outputRef(key)` a `StateRef<T>`. A ref used as a string, such as `new URL(queue.url)`, now fails the type check. `outputRef` no longer removes `undefined` from an optional output.

- `@notation/resource` exports the types `Input<T>`, `DeepInput<T>`, `Resolved<T>`, `ResolvedValues<T>` and `Derived<T>`, and `text`, `all` and `map` to compute with refs: `` text`${queue.arn}-*` ``, `api.url.map((url) => new URL(url).host)`. `isDerived` checks whether a value is a derived value. Plan shows a derived value once its refs are known, and only its own path is unknown before then. A resource's `config` and `contribute` take `DeepInput` of the params. `text` and `all` are marked `@resource`, so a function bundle that calls them fails to build.
- Each ref has a `kind`: `"output"`, `"credential"` or `"state"`. `StateOutputRef` is removed: a `~state` ref has the kind `"state"`. `isCredentialRef` and `isStateRef` check the kind. `outputRef(key)` throws for a credential key: use `credentials.<key>`.
- `deriveParams` receives config, and the config of its dependencies, with their refs filled in. At plan, reading an unknown ref in config throws `PendingOutput`. So does reading a credential that plan expects deploy to rotate. Reading a value in config that is a ref to the resource's own physical name, or a credential, throws, at plan and at deploy. A `deriveParams` that annotates `deps` types it as `ResolvedDependencies<Deps>`. A helper that `deriveParams` calls with `deps.x`, and that types its argument as a resource instance type such as `WorkerScriptInstance`, must type it as `ResolvedDependency<WorkerScriptInstance>` instead, because the type of `deps.x` leaves out the instance's private members. `@notation/resource` exports `ResolvedDependency`. Each entry of `deps` is now a view of the dependency, an object whose prototype is the dependency, at plan and at deploy, so `deps.x === x` is false. Before, deploy passed the instance. The `config` of each view is a copy, so a change to `deps.x.config` doesn't change `x.config`.
- `contribute` takes a `~state` ref only where the value can be `undefined`, because the ref resolves to `undefined` when state has no record. A contribution can leave out a field of an object, but not an item of an array: `DeepPartial` keeps the items of an array required, and so does the type of the items that `collect` receives. A `collect` rule can declare items narrower than that, and `contribute` takes the declared type. A Worker script's `Bindings` and `DurableObjectTransferSources` take whole items, where they took any value, and a Lambda role policy's `PolicyDocument` takes whole statements.
- `contribute(fn, { deps })` is deprecated, on a resource and on `kvJson()`. Contribute values with `text`, `map` or `all` instead. At deploy, the function receives the config of its deps with their refs filled in, as at plan. Its `deps` is typed as `ResolvedDependencies<Deps>`.
- A `map` function that returns a promise, a function, or an object that is not a plain object or an array, such as a `URL` or a `Date`, fails, at any depth.
- `OutputRefStringError` names `text` and `map` as the fix.
- `@notation/aws`: `queue.arn`, `queue.url`, `bus.arn` and `bus.name` are `OutputRef<string>`. A dead-letter queue's `queue` and a `PolicyStatement`'s `Resource` take `Input<string>`. A `$lambda`'s `env` is `EnvVars`, a `Record<string, Input<string> | CredentialRef<string>>`. `lambda.env()` and `LambdaEnv` give plain values, and a credential as a `string`. `lambda.env()` throws in infra code, where it returned the declared values, which can be refs. The role policy's params hold `ResolvedPolicyStatement`. `@notation/aws/lambda` exports the types `OutputRef`, `CredentialRef`, `Derived`, `Resolved` and `ResolvedValues`, which the type of a declaration names.
- `@notation/cloudflare`: a Worker's binding takes `Input<string> | CredentialRef<string>`. An output ref or a derived value that isn't a credential binds as plain text, where it failed before. A Worker that binds a `~state` ref fails. A Worker can bind an R2 bucket whose `Jurisdiction` is a ref or a derived value, and plan shows that binding as unknown until the jurisdiction is known. `environmentVariables` of a container take `Record<string, Input<string>>`, and `kvJson()`'s `value` and `contribute` take `DeepInput`. When the `Condition`, `ExpiresOn` or `NotBefore` of an `AccountToken` holds an unknown ref, plan marks every param that config doesn't set as unknown. Before, only the path of the ref was unknown. `@notation/cloudflare/workers` exports the same types as `@notation/aws/lambda`, for the type of a Worker declaration.
- `@notation/build`: `Bundle` types its config as plain values. The analysis of a module counts a tagged template, such as `` text`…` ``, as a call of its tag.
